# v1.0 验收测试规范

状态：测试设计，全部未执行。需求来源：[完整规划](requirements.md)。T01–T16 保留原编号，T17 起补充边界与稳定性。

## 执行与证据规则

记录提交号、载荷哈希、macOS/Swift 版本、架构、机型、设备连接方式、系统自然滚动设置及授权状态。以关闭服务时行为为对照，不更改全局自然滚动设置。真实服务测试使用专用测试账户或隔离配置，结束后清理。故障注入不破坏个人安装。

每例记录：执行人/日期、前置状态、实际步骤、实际结果、证据路径、PASS/FAIL/BLOCKED/未验证、关联缺陷及复测结果。模拟测试不能证明真实硬件兼容性。缺设备或权限标未验证，不计通过。

## 用例

默认前置：已构建候选版本、可用可滚动页面、普通离散鼠标和触摸板；涉及开启时已授权。特定首次安装、错误及跨机器条件以步骤为准。

### T01 普通鼠标向上滚动（F01）

- 操作：开启服务，在可滚动页面向上滚轮。
- 预期：相对关闭时方向反转，符合传统滚动。
- 证据：记录实际结果及必要日志/截图；当前状态：未验证。

### T02 普通鼠标向下滚动（F01）

## 自动化与人工分工

纯函数测试覆盖 T17/T18；隔离脚本测试覆盖 T09/T11/T16/T25/T26/T30 的可模拟部分；系统集成覆盖状态、健康及服务生命周期。其余真实输入、权限、同步、登录和硬件兼容性须人工验证。版本比较、安装幂等性、服务切换均必须有自动化覆盖。

## 兼容矩阵

Apple Silicon 与 Intel 分别记录系统版本和测试结果。优先：MacBook 内置触摸板、小米无线鼠标 3 彩色版、普通 USB 鼠标、蓝牙机械滚轮、2.4G 鼠标。可选：MX Master、Logitech 静音办公鼠标、平滑滚轮鼠标、Magic Mouse。每款记录实际 continuous 分类；连续鼠标不反转属于已知限制，但诊断必须清楚。

## 发布门槛

完整需求第十三章全部勾选且有证据才可声明 v1.0 完成。P0 全部验收；P1 中卸载、升级回滚等已列入完成标准的要求不得仅以优先级低为由跳过；P2 水平独立控制不阻塞 v1.0，但水平默认保留必须验证。FAIL 必须修复复测；BLOCKED/未验证不能冒充通过。性能使用实际测量数据，不硬编码承诺。

## Phase 3 补充验收

自动化需执行 make shortcut-test 与 make check-shortcut，分别验证整次点击并发、离仓库载荷、版本/源码/脚本更新、失败停止切换及载荷清理后的恢复。人工 T14/T31：按 Shortcuts/README.md 创建一条 Mouse Scroll Toggle，使用实际 Shell 动作运行、授权、三次点击验证开关，再在第二台 Mac 同步并独立安装授权。记录 macOS/Swift/架构及实际结果；不能因载荷文件存在就标记创建或同步通过。

## Phase 4 本轮结果

T01–T31 的逐项层次、环境、实际操作、期望/实际、证据及剩余缺口集中在 [phase4-evidence.md](phase4-evidence.md)，兼容性在 compatibility.md，性能记录在 performance.md。自动化 PASS 仅覆盖相应层，不直接将整项硬件/跨设备验收勾为完成。真实系统入口为明确 opt-in 的 Tests/system-tests.sh --live；退出登录/休眠/重启和撤销权限由用户安排。
