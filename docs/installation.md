# 安装、使用与卸载（目标流程）

**当前尚未实现，本文不是可执行安装指南。**

前置条件：macOS 用户图形会话、Apple Silicon 或 Intel、可用 Swift 编译工具链、系统允许快捷指令运行 Shell。最低 macOS/Swift 版本待实测确定。

首次运行主快捷指令 Mouse Scroll Toggle：检查平台和 swiftc → 缺工具链时提示安装 Xcode Command Line Tools → 写入源码并本机编译 → 生成用户配置 → 检查辅助功能权限 → 启动并确认 Event Tap 健康 → 输出“鼠标滚轮反转：已开启”。权限必须由用户手动授予，授权后重试；不得假报开启。

后续点击按真实状态切换，返回“鼠标滚轮反转：已开启/已关闭”。安装不直接执行多余切换。相同源码不重复编译。退出登录或重启后保持关闭。

计划卸载入口为 Scripts/uninstall.sh：先卸载本项目服务，再清理自有二进制、配置、缓存及日志；不删除其他项目文件。系统辅助功能授权记录由用户在系统设置中按需移除。主快捷指令及其 iCloud 副本由用户单独删除，不应误称卸载已清除系统授权和云端内容。

发布前须补充经过实际验证的完整命令、快捷指令操作步骤及支持版本。
