# 已知限制与待决策项

Phase 1 核心已实现；服务控制及安装已实现，快捷指令自包含载荷已实现，UI已创建且正常开关/显示经用户确认，原生导入和iCloud同步未验证，本机内置触摸板及小米无线鼠标3/2.4G基本功能经用户观察通过，其他设备未验证。

v1.0 不提供 GUI、菜单栏、按键映射、指针加速度调整、自动登录启动、Magic Mouse 精确识别或特殊游戏/直接 HID 读取兼容保证。连续事件鼠标可能不反转，默认优先保护触摸板。水平独立控制为 P2，默认不改变水平滚动。

实施前需明确：最低 macOS/Swift 版本；健康状态通信与防陈旧机制；日志轮转限额；并发锁；退出码；签名与授权链；升级原运行状态恢复；许可证选择。需求未指定许可证，不擅自授予授权。

健康协议、锁、退出码和日志策略已确定，见 installation.md。更新事务不覆盖断电/SIGKILL；前台实例活跃时脚本会拒绝安装、停止及卸载，提示关闭前台实例；核心锁不阻止用户手工改文件。异常进程采用手动 start 恢复，没有自动重启。最低支持版本、Intel、具体签名授权条目仍待核对，真实 Tap 已有本轮健康证据。

回滚失败可能暂时留下不完整安装，脚本返回失败并保留完整旧快照与恢复脚本，不会启动文件恢复未完成的核心。需要排除权限/磁盘/launchctl 错误后执行恢复命令。本轮真实前台 Tap、SIGINT清理及后台信号生命周期已验证；真实 Tap 禁用恢复、权限撤销及登录休眠仍需单独验证。

Phase 3 仅交付自包含 .sh 载荷及人工创建步骤，不提供未经验证的原生 .shortcut 格式。旧数字版本拒绝执行；同版本不同内容无法推断新旧，会显示提示后更新，因此发布者必须递增 VERSION。载荷不负责下载或自动替换云端快捷指令。控制锁等待 10 秒，首次编译较慢时并发点击可能返回忙碌；请稍后重试。SIGKILL/断电不能保证清理解包目录，已准备的事务备份仍留在本机配置目录。最低 macOS/Swift 版本仍未建立兼容矩阵，Intel 是本机编译设计而非已实测承诺。

Phase 4 已实现 doctor，默认脱敏，部分字段可能因缺文件、工具或宿主权限显示 UNKNOWN；诊断健康检查有有限挑战文件副作用。真实 Tap 创建/健康及本机生命周期已获得本轮证据，其他 CPU 架构、设备和实际快捷指令宿主不能据此推断。性能采样包含外部 ps 和每10秒健康挑战开销，不能解释为核心平时轮询，也不能据 CPU 指标声称无输入延迟。

权限撤销仍不应简单按单条目判断：本轮同一二进制条目关闭后不同启动宿主出现失败/成功两种实际结果，见测试报告。运行中撤销完整链与UI错误展示仍未完成，不作为系统权限绕过或全部撤销验收通过的证据。
