# Mouse Scroll Toggle 快捷指令

当前未生成 shortcut-payload.sh 或可导入 .shortcut，尚不能使用。

目标仅一个主快捷指令：Mouse Scroll Toggle。载荷内嵌 Swift 源码、安装、启停和版本管理逻辑，不依赖仓库克隆、GitHub 下载或 Homebrew，无机器特定绝对路径，支持路径空格。

实现后的人工创建流程：新建同名快捷指令 → 添加运行 Shell 脚本动作并选择 Zsh → 粘贴生成的完整载荷 → 运行并按提示授权 → 再次运行验证开关 → 在第二台开启快捷指令 iCloud 同步的 Mac 上验证独立安装。具体界面和 Shell 执行设置待实测补充。

iCloud 只同步快捷指令和源码载荷；二进制、权限、服务、状态、日志、缓存由各 Mac 独立管理。不能仅凭本机运行成功认定同步通过。无法可靠生成导入文件时交付文字操作说明，不宣称已创建快捷指令。
