# Mouse Scroll Toggle

Phase 3 已交付完整自包含载荷 [shortcut-payload.sh](shortcut-payload.sh)。它是生成产物，包含正式 Swift 源码、共享控制函数、事务安装器和点击编排；不包含二进制、机器路径或凭据。不是可直接导入的 `.shortcut` 文件。Phase 4 已在本机应用内创建并保存，Shell 执行开/关/开状态已实测；结果浮窗文案已由用户确认，原生导入及 iCloud 同步仍未完整验证。

## 创建一条主要快捷指令

1. 在 Mac 上打开“快捷指令”，新建快捷指令，命名为 **Mouse Scroll Toggle**。
2. 添加“运行 Shell 脚本”（Run Shell Script）动作，将 Shell 选为 `/bin/zsh`。保持普通用户执行，不使用管理员权限；不传入快捷指令输入，无需勾选其他后台执行选项。
3. 删除默认示例，将 shortcut-payload.sh 的**全部文本**粘贴到动作中（不是文件路径，也不要粘贴 Markdown 围栏）。不要将动作替换为仓库脚本路径，否则第二台 Mac 不能独立使用。
4. 在其后添加“显示结果”（本机 macOS 27.2.1 中文名称为“显示内容”），输入选择上一个动作的输出。成功时只显示“鼠标滚轮反转：已开启/已关闭”。非零退出由 Shell 动作显示错误，详细原因和恢复命令写 stderr；不要添加吞掉错误后仍显示成功的动作。
5. 若脚本执行被快捷指令安全设置阻止，在“快捷指令 → 设置 → 高级”检查“允许运行脚本”，由用户决定开启。见 [Apple 高级隐私与安全设置](https://support.apple.com/en-gb/guide/shortcuts-mac/apdfeb05586f/mac)。该宿主限制不同于 Event Tap 的辅助功能授权。
6. 首次点击：检查平台和会话 → 本机编译安装 → 尝试启动 → 检查实时 Tap 健康。缺少工具链时按提示安装 Xcode Command Line Tools（可手动 `xcode-select --install`），再运行；不需要 Homebrew。
7. 若提示辅助功能未授权，打开“系统设置 → 隐私与安全性 → 辅助功能”，按实际启动链添加/允许对应条目，然后再次运行。稳定二进制在 `~/.local/bin/mousescrolltoggle`；具体宿主授权条目尚未通过快捷指令应用实测，不能保证只授权某个宿主即可。
8. 获授权后，分别点击三次验证开启、关闭、开启；在鼠标及触摸板上确认实际行为。应用内操作和硬件结果需自行验收，不能用本仓库模拟测试替代。

## iCloud 与第二台 Mac

在同一 Apple Account 的两台 Mac 上，打开“快捷指令 → 设置 → 通用”，启用 iCloud 同步。等待 Mouse Scroll Toggle 出现在第二台 Mac，检查 Shell 动作中完整载荷仍存在，运行后在第二台 Mac 独立安装工具链并授权。Apple 的 [同步说明](https://support.apple.com/guide/shortcuts-mac/sync-shortcuts-apdb3a4240b0/mac) 介绍了此设置。

iCloud 只同步快捷指令及内嵌文本；本机编译二进制、辅助功能权限、服务、日志、运行状态及事务备份不在同步范围。退出登录后不自动启动。不支持在 iPhone/iPad 上执行 macOS 载荷。尚无第二台 Mac 同步验收证据。

## 生成、更新与版本

```sh
make shortcut
make check-shortcut
make shortcut-test
```

版本唯一来源为仓库根目录 VERSION（当前 0.3.0，开发阶段版本，不表示 v1.0 验收完成）。更新正式源码后重新生成，再把完整新载荷替换到原快捷指令的同一 Shell 动作中；不要额外创建第二条切换指令。生成不含时间戳，相同输入逐字节一致。发布更新应递增三段数字版本。

点击全程持有控制锁，最多等待 10 秒，超时返回 75 提示忙碌。第一次安装仅启动一次；原先健康运行时，即使有更新，本次点击最终仍关闭；停止或已加载但不健康时尝试启动并重新检查。更新失败不继续切换。未托管核心锁被占用时拒绝操作。成功输出前会再次验证状态，日志 READY 不作为证据。

每次点击计算核心和运行脚本摘要；核心相同不重新编译、不替换二进制，仅版本或脚本变化也使用本次载荷的控制逻辑。较旧数字版本返回 78 并拒绝降级和切换；同版本不同摘要会明确提示内容变化后更新，因此发布时必须递增版本，不能靠同版本摘要推断新旧顺序。Phase 2 的无 bundle.sha256、版本为 1.0.0-dev 的安装允许一次迁移。版本文件表示安装产物版本，不表示已经获得权限或成功运行。

未完成事务会阻止新的安装/点击。按错误给出的 `/bin/zsh …/recover.sh` 先恢复，再重试。备份保存在本机配置目录，含完整旧文件和独立共享模块，不依赖已清理的载荷临时目录。不要删锁或叠加升级。完整生命周期与退出码见 [安装说明](../docs/installation.md)。

## 导入与签名

已核实本机 `shortcuts --help` 只有 run/list/view/sign，没有从 Shell 文本创建快捷指令的公开子命令。`shortcuts sign --mode anyone --input <原始快捷指令> --output <已签名快捷指令>` 可以签名已有快捷指令；Apple 的 [命令行说明](https://support.apple.com/en-gb/guide/shortcuts-mac/-apd455c82f02/mac) 也说明了签名与共享。签名不是将 `.sh` 转成 `.shortcut`，分享签名会向 Apple 提交快捷指令用于验证。

本项目没有可靠原始快捷指令导出模板，不拼凑私有格式，所以本轮交付文字创建步骤和完整载荷，不声称已生成、导入、签名或同步成功。可在完成上述人工创建后通过快捷指令应用的分享/导出界面交付原生快捷指令，并在另一台 Mac 导入验收。

已健康运行且需要核心更新时，本次关闭意图会传给共用安装器：停止旧服务、提交已验证编译产物后保持停止，不再为了恢复运行而启动新服务后立即关闭。独立安装默认保持原运行状态；更新失败回滚仍尝试恢复原服务。

## 自包含诊断

本轮载荷同时携带 doctor.sh/runtime.sh。将完整载荷保存为本地 .sh 文件，执行 `/bin/zsh shortcut-payload.sh --doctor` 可以在没有仓库时取得诊断，不会执行安装或切换。无参数才表示正常点击；不要给主快捷指令意外传入 --doctor。普通报告隐去 HOME，默认诊断不会改变授权或创建 Tap。已加载服务会写健康挑战文件并向服务发送 SIGUSR1。报告“PERMISSION=AUTHORIZED”只表示该诊断上下文有权限，不替代 “TAP=HEALTHY”。

本轮已在本机保存 Mouse Scroll Toggle；默认 Shell 为 /bin/zsh、管理员关闭，“显示内容”自动绑定 Shell 脚本结果。三次运行的服务状态已独立验证；自动化无法读取浮动结果窗口，但本轮用户已确认三次文字与实际滚动正确。不因编辑器保存成功就声明整个 UI/同步验收完成。
